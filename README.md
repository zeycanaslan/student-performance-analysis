# Öğrenci Sınav Performansı Analizi - Box Plot Görselleştirme

Bu proje, Kaggle üzerindeki "Students Performance in Exams" veri setini kullanarak öğrenci matematik notlarını Box Plot (Kutu Grafiği) yöntemiyle analiz eder ve görselleştirir.

## Proje İçeriği

Proje kapsamında aşağıdaki kütüphaneler kullanılarak veri analizi ve görselleştirme yapılmıştır:
- **Pandas**: Veri setinin okunması ve işlenmesi için.
- - **Matplotlib**: Temel görselleştirmeler için.
  - - **Plotly**: Etkileşimli kutu grafikleri (box plot) oluşturmak için.
   
    - ## Kullanılan Veri Seti
   
    - Bu çalışmada kullanılan veri seti, öğrencilerin sınav performanslarını (matematik, okuma ve yazma notları) ve çeşitli demografik faktörleri içermektedir. Notebook içerisinde özellikle matematik notlarının dağılımı üzerine odaklanılmıştır.
   
    - ## Nasıl Çalıştırılır?
